# Credit Card Fraud Detection — ML Web Application

A machine-learning–powered Streamlit web application that detects fraudulent
credit-card transactions using the **Credit Card Fraud 2026** dataset.

## Project Structure

```
project/
├── app.py                  # Streamlit web application
├── train_model.py          # Model training script
├── requirements.txt        # Python dependencies
├── README.md
├── agent_instructions.md
├── .env.example
├── data/
│   └── credit_card_fraud_2026.csv
└── models/
    └── model.pkl           # Saved pipeline (generated by train_model.py)
```

## Quick Start — Local

### 1. Clone the repo and create a virtual environment

```bash
git clone <your-repo-url>
cd <repo-folder>
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model

```bash
python train_model.py
```

This will:
- Load `data/credit_card_fraud_2026.csv`
- Compare Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting
- Select the best model by 5-fold cross-validated ROC-AUC
- Save the full sklearn pipeline to `models/model.pkl`

### 4. Run the Streamlit app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## Deployment — Streamlit Community Cloud

1. Push the entire project to a **public GitHub repository** (include `models/model.pkl`
   or run `train_model.py` as a pre-deploy step).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repository, branch, and set **Main file path** to `app.py`.
4. Click **Deploy**.

> **Tip:** Commit `models/model.pkl` to the repository so the deployed app does
> not need to retrain at startup. If the file is too large for Git, add a
> `@st.cache_resource` warm-up call that runs `train_model.py` on first launch.

## Features

| Feature | Description |
|---|---|
| `amount_usd` | Transaction amount in USD |
| `merchant_category` | Category of the merchant |
| `card_type` | Visa / Mastercard / Amex / Discover / RuPay |
| `auth_method` | OTP / 3D Secure / PIN / Biometric / No Auth |
| `channel` | Online / POS / Contactless / In-App / ATM |
| `device_type` | Android Phone / iPhone / Tablet etc. |
| `is_foreign_transaction` | Transaction made in a foreign country |
| `hours_since_last_txn` | Time gap from previous transaction |
| `txn_count_last_24h` | Number of transactions in the last 24 h |
| `distance_from_home_km` | Distance from the cardholder's home |
| `card_age_months` | Age of the card in months |
| `customer_age` | Age of the cardholder |
| `account_balance_usd` | Current account balance |
| `is_new_merchant` | First-time merchant |
| `used_vpn` | VPN detected during transaction |
| `ip_country_mismatch` | IP country differs from card country |
| `billing_shipping_mismatch` | Billing and shipping addresses differ |
| `cvv_retry_count` | Number of CVV retry attempts |
| `velocity_score` | Transaction velocity risk score |
| `time_of_day_hour` | Hour of the transaction (0–23) |
| `day_of_week` | Day of the week (0 = Mon … 6 = Sun) |
| `is_ai_generated_scam_attempt` | AI-scam attempt flag |
| `merchant_risk_score` | Merchant-level risk score |
| `prior_disputes` | Number of prior disputes by the customer |

## Target

`is_fraud` — Binary classification (0 = Legitimate, 1 = Fraud)

## Models Compared

- Logistic Regression
- Decision Tree
- **Random Forest** *(typically best)*
- Gradient Boosting

The best model is selected automatically by ROC-AUC.
